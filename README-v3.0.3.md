# Nacar Distribuição v3.0.3 — Propostas comerciais

Inclui criação de propostas, validade, condições, descontos, impressão/PDF pelo navegador, WhatsApp e conversão em pedido. Também corrige a limpeza do formulário de fotos.

1. Execute `supabase/upgrade-v3.0.3.sql` uma vez.
2. Copie o `.env.local` da versão anterior.
3. Rode `npm install`, `npm run typecheck`, `npm run build` e `npm run dev`.
