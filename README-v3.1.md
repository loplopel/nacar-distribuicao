# Nacar Distribuição v3.1 — NACS Intelligence

## Recursos
- Assistente comercial baseado em dados reais, sem custo por chamada externa.
- Score comercial e índice de potencial.
- Tendência de crescimento ou risco.
- Frequência média de compra.
- Estimativa da próxima compra.
- Probabilidade de fechamento.
- Alertas automáticos.
- Marcas esquecidas.
- Recomendação de reposição por produto e quantidade.
- Central de inteligência para Admin e Vendedores.

## Instalação
1. Copie o `.env.local` da versão anterior.
2. Execute `supabase/upgrade-v3.1.sql` uma vez no Supabase.
3. Rode `npm install`, `npm run typecheck`, `npm run build` e `npm run dev`.
